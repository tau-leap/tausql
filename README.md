# TauSQL

Import CSV, TSV and Parquet files into a local DuckDB on your Mac and query them with SQL.

- Requires: Mac with Apple Silicon
- Website: https://tauleap.com/product/tausql/
- Download: [Releases](https://github.com/tau-leap/tausql/releases)
- Demo (Japanese narration): https://youtu.be/vQSogDeNN4w
- Support: support@tauleap.com

No account, no analytics. Data stays in a local DuckDB file.
10-day full trial, then the core stays free. Pro: $2.99/mo, $24.99/yr or $49.99 lifetime.

This repository hosts the README and release builds only.
